## Publishing later

This repository is private and GitHub Pages has not been enabled. Before publishing, replace every occurrence of https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/ in index.html with the final public HTTPS URL, including its trailing slash. This updates static canonical and social-preview metadata. Do not claim the preview works until the site and assets/share-preview.jpg are public and checked.

For GitHub Pages, configure Settings → Pages to serve the main branch root when hosting is available for your repository. All assets use relative paths. The supplied portrait and SVGs require no additional stock attribution.
